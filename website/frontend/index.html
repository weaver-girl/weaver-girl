Weaver-Girl

Home Docs Plugins API

Modular Java bytecode instrumentation built on ByteBuddy

Inspired by SkyWalking and OpenTelemetry Java Agent.

java -javaagent:weaver-girl-agent.jar -jar your-app.jar

Features

  • 16 built-in plugins
  • SPI-based plugin discovery
  • ByteBuddy Advice interception
  • Dynamic attach
  • Hot reload
  • Circuit breaker
  • Adaptive sampling
  • REST API and Prometheus metrics
